DashboardSkybox Studio
Jatuhkan gambar di sini atau klik untuk memilih, atau tempel (Ctrl+V). JPG, PNG, WebP. Gambar 2D biasa atau panorama 360°; langsung dikonversi.

Belum ada gambar.

Mulai dalam 3 langkah
  1. Jatuhkan gambar (panorama 2:1 atau gambar biasa — dikonversi otomatis), atau coba langit contoh di bawah.
  2. Atur seperlunya — warna, posisi, dan watermark ada di Pengaturan Lanjutan kalau perlu.
  3. Buka tab Roblox untuk mengunggah 6 sisi dan memasangnya ke game.

3 · Pasang ke Roblox

⚠️ Aset terunggah sebagai Decal, bukan Image.

Skybox bisa tampil putih karena ID Decal tidak bisa dipakai di Sky. Cara memperbaiki: di Roblox Studio buka View > Asset Manager, cari gambar (Skybox_Ft dst.), klik kanan > Copy ID, lalu isi ulang tiap sisi di bagian "Sudah punya Image ID? Isi manual" di bawah. Script dan file .rbxmx akan ikut diperbarui.

Ke-6 sisi sudah terunggah. Paling cepat: salin script Command Bar di bawah, paste di Studio, Enter — skybox langsung terpasang.

Studio: klik kanan Lighting > Insert From File, pilih file ini. 

        
        
        
Cara pakai script: di Roblox Studio buka View > Command Bar (atau tekan Ctrl+3), paste script, tekan Enter — skybox langsung terpasang di Lighting tanpa bikin Script manual.
