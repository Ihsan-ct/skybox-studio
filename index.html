Roblox Skybox Studio

Panorama 360° menjadi 6 sisi skybox Roblox. 100% diproses di browser kamu.

Jatuhkan panorama di sini atau klik untuk memilih, atau tempel (Ctrl+V). JPG, PNG, WebP; rasio 2:1

Panduan Memasang Skybox ke Roblox

        
    
          
  1. Unggah Gambar: Di Roblox Studio, buka View > Asset Manager > Images lalu unggah keenam file PNG hasil unduhan.
    2. 
          
  2. Gunakan Image ID (Bukan Decal ID): Klik kanan gambar yang sudah diunggah di Asset Manager > Copy ID. Image ID biasanya dapat disalin dari Asset Manager, tetapi antarmuka Roblox bisa berubah sehingga cek dokumentasi Creator Hub bila skybox tampil putih atau abu-abu.
    3. 
          
  3. Pasang Script: Buat Script di dalam ServerScriptService, lalu tempel kode di atas.
    4. 
          
  4. Jika Sisi Up/Down Terputar: Gunakan tombol rotasi di grup Koreksi orientasi pada panel kiri aplikasi ini, lalu ekspor ulang.
    5. 
        

        
Peringatan Moderasi & Hak Cipta

        
Pastikan gambar mematuhi Roblox Community Standards (bebas dari konten ofensif atau hak cipta pihak ketiga). Roblox dapat mengenakan moderasi pada akun yang mengunggah gambar terlarang.

        
Unggah Cepat Lewat Skrip Lokal

        
Bagi pengguna teknis dengan Roblox Open Cloud API Key, Anda dapat mengunggah 6 sisi dari ZIP secara otomatis memakai skrip pendamping di terminal: node upload-skybox.mjs RobloxSkybox_1024.zip --user-id ID_ANDA. Catatan: hasil unggahan lewat Open Cloud bisa berupa Decal ID, dan bila skybox putih, ambil Image ID dari Asset Manager.
