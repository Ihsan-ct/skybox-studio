Masuk untuk upload ke Roblox

Login dibutuhkan untuk upload langsung. Setelah masuk, profil akun dan riwayat upload ikut tersinkron antar perangkat; API key tetap hanya di browser kamu.

Akun Roblox

Disimpan hanya di browser ini, tidak dikirim ke server. API key dienkripsi (AES-GCM) dengan kunci perangkat sehingga terisi otomatis saat upload; isi kata sandi kalau mau perlindungan ekstra (kata sandi diminta tiap dipakai). API Key dibuat di Creator Dashboard dengan permission Assets (Read + Write), tanpa pembatasan IP.
