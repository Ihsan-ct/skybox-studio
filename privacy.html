Kebijakan Privasi

Terakhir diperbarui: 9 November 2026. NAKA Studio adalah alat gratis, bersumber terbuka (GitHub), untuk mengubah panorama 360° menjadi skybox Roblox.

Data yang diproses di browser Anda

Konversi panorama, pratinjau, dan ekspor ZIP berjalan sepenuhnya di browser. Gambar Anda tidak diunggah ke server kami.

Login Google atau Discord

Login hanya diperlukan untuk upload ke Roblox. Kami meminta akses minimal (Google: openid profile; Discord: identify) dan hanya menerima ID akun, nama tampilan, dan foto profil. Kami tidak meminta atau menyimpan alamat email, kata sandi, ataupun token akses Google/Discord. Data ini disimpan di cookie sesi bertanda tangan (HttpOnly, 7 hari) dan dihapus saat Anda klik Keluar.

API key Roblox

API key hanya diteruskan sekali per permintaan ke Roblox melalui server proxy kami. Key tidak disimpan dan tidak dicatat di server atau database. Di browser Anda, key disimpan lokal dan terenkripsi AES-GCM (kunci perangkat, atau kata sandi bila Anda mengisinya) supaya tidak perlu dimasukkan ulang.

Sinkronisasi (opsional)

Bila diaktifkan, kami menyimpan di database (Upstash Redis) ID akun login, nama tampilan, serta metadata profil Roblox (nama profil, User/Group ID, awalan nama aset) dan riwayat 20 upload terakhir (waktu, nama, ID aset). Tanpa API key.

Pihak ketiga

Situs di-host di Vercel; login lewat Google dan Discord; upload diteruskan ke Roblox Open Cloud; database oleh Upstash. Masing-masing memiliki kebijakan privasinya sendiri.

Hak Anda

Anda dapat menghapus akun Roblox tersimpan dan riwayat dari Dashboard kapan saja, atau meminta penghapusan data sinkronisasi dengan membuka isu di GitHub kami.
